# OmashelCap

Automated trading bot for [Deriv](https://deriv.com) synthetic indices — with a real-time web dashboard.

## Stack

| Layer | Tech |
|---|---|
| Bot engine | Python 3.12 + asyncio + websockets |
| API | FastAPI + WebSocket |
| Dashboard | React 19 + TypeScript + Tailwind CSS |
| Database | SQLite (dev) → PostgreSQL (prod) |
| Package manager | [uv](https://docs.astral.sh/uv/) (Python) + pnpm (Node) |
| Containers | Docker + docker-compose |

## Features

- Live WebSocket connection to Deriv API
- Market structure trend detection (HH/HL swing analysis)
- Supply & demand zone detection
- Multi-factor signal scoring (trend + EMA + RSI + Bollinger Bands + zone)
- Fixed fractional position sizing (1% per trade)
- Circuit breaker: stops after 5 consecutive losses or 5% daily drawdown
- Real-time dashboard with signal panel, trade history, and session stats
- Telegram alerts on trade open/close and circuit breaker trips
- Full SQLite trade log
- Mock mode for development without API credentials

## Quick Start (Mock Mode — No API Key Needed)

```bash
# 1. Clone
git clone https://github.com/iamMashel/OmashelCap.git
cd OmashelCap

# 2. Copy env (mock mode is on by default)
cp .env.example .env

# 3. Install Python deps
uv sync

# 4. Install frontend deps
cd frontend && pnpm install && cd ..

# 5. Start everything
./dev.sh
```

Open [http://localhost:5173](http://localhost:5173), click **START BOT**, and watch simulated trades flow in real-time.

## Live Trading Setup

1. Create a Deriv account at [deriv.com](https://deriv.com)
2. Get your API token: **Account → Security & Limits → API Token** (scopes: `read` + `trade`)
3. Register an app at [api.deriv.com](https://api.deriv.com) to get an `APP_ID`
4. Edit `.env`:

```env
USE_MOCK=false
DERIV_APP_ID=your_app_id
DERIV_API_TOKEN=your_token
TRADING_MODE=demo        # Start on demo — always
```

> **Always run on demo first.** Only switch `TRADING_MODE=real` after validating signal quality.

## Risk Disclaimer

Synthetic indices on Deriv are generated by a cryptographically secure RNG.
Binary options carry a structural house edge — at 85% payout you need >54% win rate to break even.
**Never risk money you cannot afford to lose entirely.**
Always start on a demo account.
